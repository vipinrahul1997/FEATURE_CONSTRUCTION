Feature Construction is the process of creating new features from existing data to provide useful information to a machine-learning model.

The goal is to create features that help the model better understand patterns and relationships in the data

Feature construction is the process of creating new meaningful features from existing data using domain knowledge, 
mathematical operations, transformations, or combinations of existing features.

Data splitting is the process of dividing a dataset into training, validation, and/or test sets so that a machine-learning model can be trained, 
tuned, and evaluated on unseen data.
